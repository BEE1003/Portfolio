# Unity Showcase Studio

我想做一個Unity工程師的作品集網站，要有作品集區塊和聯絡我，並且作品集區塊中可以放入個別專案當使用者點擊其中某一個專案時會跳出新的視窗顯示專案'詳細內容以及程式碼，作品希望可以用影片檔

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://code-and-visuals.lovable.app
